# Spin — Minecraft Forge 1.20.1

Standalone Forge mod inspired by the legacy Spin addon resources.

## Target
- Minecraft 1.20.1
- Forge 47.x
- Java 17
- Mod ID: `spin`

## Development status
Project bootstrap. Legacy art/audio assets are being migrated; gameplay code and client integration are being implemented for the standalone mod.

## Build
Run `gradlew build` (wrapper will be added with the Gradle project files). The mod JAR will be in `build/libs/`.
